The documents here trace my (EHN's) experiments in using IEEE-style
software engineering documents as tools for AI-assisted software
development.

The documents associated with my initial attempt can be found in the
first_start directory. This was found to be very heavy weight for what
is actually needed, and I ultimately abandoned this full process.

SP-3142.md is a second attempt, switched to mid development, and
features a might lighter-weight single document. This was in
improvement, but I think the way I used the LLM tool to maintain the
document itself was a mistake: I should have written more (or even
all) of issue working document (SP-3142.md) by hand rather than using
AI tools, because it had a tendency to go overboard.
